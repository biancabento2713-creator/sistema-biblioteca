Sistema de Cadastro de Biblioteca

Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo de gerenciar o cadastro e a consulta de livros de uma biblioteca.

Funcionalidades

- Cadastrar livros com título, autor e ano de publicação.
- Listar todos os livros cadastrados.
- Buscar livros.
- Registrar empréstimos e devoluções.
- Contar os livros do acervo.
- Ordenar os livros.
- Remover livros cadastrados.

Tecnologias utilizadas

- Python
- JSON para armazenamento dos dados.

Como executar

1. Abra o notebook do projeto no Google Colab.
2. Execute as células do código.
3. Escolha uma opção no menu e siga as instruções exibidas.

Objetivo

Aplicar os conceitos de programação em Python, funções, listas, dicionários, arquivos JSON e organização de código.
